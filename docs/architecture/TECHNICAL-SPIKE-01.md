# Technical Spike 01

## Geometry
Evaluate candidate kernels against:
- solid creation
- boolean union/difference/intersection
- offset
- section/projection
- tolerance behavior
- invalid solid recovery
- deterministic results
- performance
- .NET integration
- commercial/open-source licensing

## Storage
Evaluate:
- JSON baseline
- SQLite/document container alternatives
- schema versioning
- migration
- atomic writes
- project size
- asset embedding
- recovery

## Gate
No final geometry or project format is selected until measurable evidence is recorded in ADRs.
